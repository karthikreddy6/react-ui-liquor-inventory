API notes for React (seller update)

Base URL
- http://127.0.0.1:5000

1) Read current stock (seller uses this to see present stock)
- GET /stock
- Response: JSON list of stock items with fields like id, brand_name, pack_size_case, pack_size_quantity_ml, total_cases, total_bottles

2) Update stock after today's sales
- POST /seller/stock-update
- Content-Type: application/json
- Body (by id):
  {
    "stock_id": 12,
    "available_cases": 50
  }
- Body (by composite keys):
  {
    "brand_number": "1024",
    "pack_size_case": 12,
    "pack_size_quantity_ml": 750,
    "available_cases": 50
  }

Rules
- Seller enters available cases after today's sale.
- Bottles are computed by server using pack_size_case.
  Example: if pack_size_case = 12 and available_cases = 50, then total_bottles = 600.
  If pack_size_case = 24, then total_bottles = 1200.
- total_amount is recalculated from unit_rate_per_bottle (if present) or rate_per_case.

Response (success)
- { status, stock_id, brand_number, brand_name, pack_size_case, pack_size_quantity_ml, total_cases, total_bottles, total_amount }

Errors
- 400 if available_cases is missing or invalid
- 400 if stock lookup keys are incomplete
- 404 if stock item not found

3) Daily Sell Report & Finance Workflow

• POST /seller/sell-report
  This creates the stock sell report for a specific date (e.g., 2025-12-01).
  It does NOT include finance details like PhonePe, Cash, Income, or Expenses.

• POST /seller/sell-finance
  To make financial details appear in the PDF report, you MUST submit this for the same report_date.

  Example JSON for POST /seller/sell-finance:
  {
    "report_date": "2025-12-01",
    "phonepay_entries": [
      { "date": "2025-12-01", "amount": 25000 }
    ],
    "cash_entries": [
      { "date": "2025-12-01", "amount": 12000 }
    ],
    "outside_income": [
      { "name": "Extra Income", "amount": 3000 }
    ],
    "expenses": [
      { "name": "Transport", "amount": 1500 },
      { "name": "Food", "amount": 800 }
    ]
  }

Flow:
1. POST /seller/sell-report (Stock data)
2. POST /seller/sell-finance (Financial data)
3. GET /reports/sell-reports/[report_date]/pdf (Generate PDF)
